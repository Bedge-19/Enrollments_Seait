# SEAIT Enrollment System - Design System

## Core Identity
**Vibe:** Vibrant, Energetic, Institutional, Modern  
**Theme:** Light mode default with crisp, high-contrast surfaces.

## Color Palette
- **Primary (SEAIT Orange):** `#FF8C00`
- **Primary Dark:** `#CC7000`
- **Primary Light:** `#FFB77D`
- **Primary Container:** `#FFDCC3`
- **Accent (Navy Blue):** `#0F4C81`
- **Accent Dark:** `#0A365C`

## Surface & Backgrounds
- **Background:** `#F8FAFC` (Slate 50) - Very soft cool gray
- **Surface (Cards):** `#FFFFFF`
- **Surface Hover/Focus:** `#F1F5F9` (Slate 100)

## Text Colors
- **Text Primary:** `#0F172A` (Slate 900)
- **Text Secondary:** `#64748B` (Slate 500)
- **Text Muted:** `#94A3B8` (Slate 400)
- **On Primary:** `#FFFFFF`

## Typography
- **Font Family:** `Work Sans`, sans-serif
- **Scale:**
  - H1: 36px, 800 weight, -0.02em tracking
  - H2: 28px, 700 weight, -0.01em tracking
  - H3: 20px, 600 weight
  - Body Lg: 16px, 500 weight
  - Body: 14px, 400 weight (System default)
  - Small: 12px, 500 weight

## Elevation (Glassmorphism & Cards)
- **Shadow Sm (Buttons):** `0 2px 4px rgba(15, 23, 42, 0.05)`
- **Shadow Md (Cards):** `0 10px 25px rgba(15, 23, 42, 0.05), 0 4px 10px rgba(15, 23, 42, 0.03)`
- **Shadow Lg (Modals/Hero):** `0 20px 40px rgba(15, 23, 42, 0.1)`

## Shapes & Radii
- **Radius Sm:** `6px`
- **Radius Md (Inputs/Buttons):** `12px`
- **Radius Lg (Cards):** `20px`
- **Radius Pill:** `999px`

## Input States (Floating Label Style)
- **Default:** Border `transparent`, Background `#F1F5F9`, Text `#0F172A`
- **Hover:** Background `#E2E8F0`
- **Focus:** Border `#0F4C81`, Background `#FFFFFF`, Box-shadow `0 0 0 4px rgba(15, 76, 129, 0.15)`
